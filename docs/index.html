About

Selected work

Robot control from the TUM lab, engineering software from Airbus and open-source simulations. Open a project for the challenge, method and outcome.

  • Challenge
    Model-based controllers need accurate kinematics and dynamics, but a robot's masses and inertias are rarely known precisely.
    My contribution
    Modelled planar serial robots with modified Denavit–Hartenberg parameters, homogeneous transformations, Jacobians and Lagrangian dynamics. Identified the inertial parameters using Fourier excitation trajectories, a minimal regressor and least-squares estimation.
    Methodology
    1. Forward kinematics from modified DH parameters
    2. Jacobians and Lagrangian equations of motion
    3. Dynamics written as linear in the parameters, reduced to a minimal set
    4. Fourier excitation trajectories
    5. Least-squares estimation of the parameters
    Tools
    MATLAB, Simulink

  • Challenge
    Robot dynamics are nonlinear and coupled: each joint's motion changes the torque the others need. Fixed-gain PID handles this only approximately, especially at higher speeds.
    My contribution
    Implemented PI/PID and computed-torque controllers for joint trajectory tracking, along with state feedback and Luenberger and disturbance observers.
    Methodology
    Computed-torque control uses the dynamic model to cancel the nonlinear terms, leaving linear error dynamics set by the gains: τ = M̂(q) (q̈d + KD ė + KP e) + Ĉ(q, q̇) q̇ + ĝ(q) The arm at the top of this page runs this control law live, with a deliberately imperfect model so a small tracking error stays visible.
    Tools
    MATLAB, Simulink
    Results
    [Add a result you can back up, e.g. tracking error of PID vs computed torque on the same trajectory]
  • Challenge
    Computed-torque control degrades when the model is wrong, and the parameters can change, for example with a payload. Physical interaction also needs controlled compliance and reliable detection of contact.
    My contribution
    Implemented Lyapunov-based adaptive and impedance controllers, and force and collision observation.
    Methodology
    Choose a Lyapunov function that combines tracking error and parameter error, then derive the parameter update law so that its time derivative is never positive. The tracking error then converges while the parameter estimates adapt online.

    MATLAB, Simulink
