# Hi, I'm Aaron 👋

Master's student at the **Technical University of Munich (TUM)**, focused on **control systems, modelling & simulation, robot learning (Physical AI), and test & validation**.

I like taking a physical system, building a model of it, designing a controller (classical or learned), and then showing with tests that it really meets its requirements, including when the real system differs from the model.
